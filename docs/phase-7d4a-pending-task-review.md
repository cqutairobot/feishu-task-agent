# Phase 7D-4A：待确认任务审核

Phase 7D-4A 为低置信度任务补齐人工审核闭环。`pending` 不是正式待办：它不会
私聊负责人，不生成截止提醒，也不能由负责人通过私聊或卡片修改生命周期。

## 管理后台

任务总览新增“待审核”筛选。存在待审核项时，右侧关注卡优先提示管理员处理；
打开任务详情可查看机器人保存的证据消息、负责人、截止时间和识别置信度。

管理员有两个明确操作：

- **确认是真实任务**：`pending → todo`，生成截止提醒，并向每位负责人私聊一次
  新任务通知。
- **不是任务，撤销**：`pending → cancelled`，保留误识别审计，不给候选负责人
  发送新任务通知。

审核前仍可看到任务内容，但标题、负责人和截止时间编辑保持关闭。管理员先确认
任务，再使用既有纠错功能，避免在尚未确认的模型结果上产生复杂状态组合。

## 权限和原子性

`confirm` 只允许从管理后台发起。服务端从 HttpOnly 会话恢复操作人，刷新当前
飞书成员并重新校验精确群管理员权限。浏览器只提交审核动作和一次性请求 ID；
重复提交返回同一结果，复用请求 ID 执行不同操作会被拒绝。

任务状态、`management_page` 生命周期审计、提醒计划和负责人私聊通知在同一个
SQLite 事务中提交。迁移 `20260823_0022` 扩展生命周期约束，允许审计
`confirm: pending → todo` 以及 `invalidate: pending → cancelled`。

`confirm` 被明确排除在 LLM 结构化输出契约之外，也不开放给私聊自然语言命令或
任务卡片按钮，因此模型和普通负责人都不能绕过管理员审核。
