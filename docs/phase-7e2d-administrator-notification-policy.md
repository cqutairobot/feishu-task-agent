# Phase 7E-2D：每群管理员通知对象

## 范围

每个群可以独立选择管理员类私聊通知的接收范围：

- `all`：全部当前管理员，默认值，与升级前行为一致。
- `selected`：指定一名或多名当前管理员。

该策略统一作用于缺少截止时间升级、任务逾期以及完成、取消、延期、纠错、恢复等
管理员通知。负责人任务创建通知、负责人截止提醒和共同负责人通知不受影响。

## 安全与队列规则

- 只有本群管理员可以修改，指定对象必须也是本群当前管理员。
- 设置按精确 `chat_id` 隔离，选择结果和前后值写入群设置审计。
- 切换策略会取消不再属于接收范围的未发送管理员通知；无截止日期和逾期通知会为
  新接收人复用或补建持久化记录，不重复发送已经终态的通知。
- 指定管理员后来离群或被撤权时，若已无任何有效指定对象，运行时安全回退到其余
  当前管理员，避免关键通知静默丢失；页面下次保存时仍要求重新选择有效对象。
- 操作人、任务负责人或共同负责人仍沿用既有自通知抑制规则，不因策略设置收到
  重复角色通知。

## 真实验收

1. 在有两名管理员的群进入“群设置”，确认默认选择“全部管理员”。
2. 改为“指定管理员”，只选择其中一名并保存；刷新后选择应保留，审计出现记录。
3. 切换到另一个群，确认仍保持默认“全部管理员”。
4. 在测试群创建一项由另一成员负责的任务，让负责人完成任务；只有指定管理员收到
   完成通知。
5. 改回“全部管理员”并保存，为后续正式使用保留默认策略。

验收结果：指定李明后，王哈完成 `T-SM` 只生成并成功发送一条给李明的管理员完成
通知；未向王哈生成管理员角色通知。随后已恢复“全部管理员”，跨群默认值和两次
设置审计均正确。
