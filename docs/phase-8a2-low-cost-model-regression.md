# Phase 8A-2：低成本模型代表性场景回归

## 范围

生产模型保持 `qwen3.7-plus`。候选模型只考虑公开价格更低且当前接口真实可用的模型，
本阶段首选 `qwen3.7-flash`，对已经由用户验收过的存储群聊上下文进行只读调用。

只读调用不创建任务、不更新任务、不生成提醒或私聊通知。

## 样本

共 12 个场景：

- 一条包含大量干扰信息和 5 条行动项的长会议纪要。
- 直接 @ 负责人并使用相对截止日期。
- 明确时间的会议任务。
- 两人共同任务。
- 一句话向不同成员安排两条不同任务。
- 两人各自交付。
- 普通询问、身份绑定命令和闲聊。
- 非工作性质的个人请求。

## 结果

- 严格 JSON Schema 和本地契约：12/12 通过，无契约错误。
- 已确认的正式任务真值：15 条，Flash 全部识别，无漏识别。
- 另有一条“明天下午 9 点前带一份黄焖鸡米饭”，Flash 输出任务、Plus 输出无任务。
  这不是纯技术差异：它具备明确负责人、动作和时间，是否登记取决于产品是只管理
  工作/科研任务，还是也管理生活跑腿任务，当前等待用户确认业务边界。
- 如果生活跑腿不属于任务，则 Flash 精确率为 93.75%，存在 1 条误识别；如果属于
  任务，则 Flash 本组 16 条全部命中，而 Plus 在该场景存在 1 条漏识别。
- 两个机械差异不计为错误：一个相对截止日期仅省略了微秒；一条旧版结果尚无
  `assignment_mode` 字段，但负责人、任务数和截止时间完全一致。

## Token 与公开原价估算

包含长纪要在内：

- Flash：输入 68145 Token、输出 34971 Token，按 32K 内北京公开原价粗略估算约
  ¥0.0416。
- 历史 Plus：输入 60252 Token、输出 18624 Token，按北京公开原价粗略估算约
  ¥0.2695。
- 该样本集 Flash 估算成本低约 84.6%，但输出 Token 明显更多。

实际账单受工作空间、地区、活动优惠和缓存命中影响，估算只用于相同样本的量级比较。

## 结论

`qwen3.7-flash` 的成本优势明显，复杂长纪要也能完整识别；唯一分歧需要先确定生活
跑腿请求是否纳入产品范围。在边界确认和更多回归完成前，不能直接替换生产 Plus，
生产配置保持不变。

后续可以选择：

1. 明确生活跑腿请求是否登记；如不登记，补充该业务边界后再对 Flash 重跑该场景及
   正式任务场景，确认不会误伤；或
2. 继续评估价格仍低于当前 Plus、但可能更稳的候选模型。
